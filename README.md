# Lyrics Plus

Synced Spotify lyrics in Minecraft 26.2 (Fabric) with a full customization panel.

- **;** or **/lyrics** – open the panel · **K** – show/hide · **- / =** – nudge sync by 0.1s
- Display modes: side lines, subtitles, big center, floating in the world (3D)
- Styles: full line, word by word, karaoke highlight
- 13 colors incl. rainbow, separate highlight color, size, background, shadow
- Song title card when a track starts, progress bar, now playing, ♪ for instrumentals
- Demo preview in the panel, English + Hebrew UI

Lyrics come from [LRCLIB](https://lrclib.net). Song detection (Windows media session / Linux D-Bus)
is based on [Spotify Lyrics](https://github.com/HBome200/Minecraft-Spotify-Lyrics) by HBome200, MIT license.
